教室大屏怎么统一管：一个网页下发全部班级的课表与作息

项目地址：https://github.com/1sIancl/ClassislandControlHub（GPL-3.0 开源）

背景

学校用 ClassIsland 做大屏之后，常见的问题是「一台一台改」：

  • 作息调整，几十个班要各改一次，改到后面记不清哪些改过；
  • 有班级反馈时间不对、课表是上周的，只能跑过去看；
  • 新装教室要配课表、作息、科目、主题，容易漏项。

IslandHub 是给这些事做的：一处配置，全部教室生效；每台教室的状态在一个页面里看得见。

怎么组成

部分装在哪做什么 A 端（服务器）内网一台机器（Windows / Linux）网页后台：统一管课表、作息、科目、外观并下发 B 端（教室端）教室机 ClassIsland 里的插件连上 A 端，自动接收并应用配置

局域网内支持自动发现，教室端不用手输 IP；数据存在学校自己的机器上（单文件 SQLite）。

上手

1. 起服务端（Linux 一条命令 / Windows 解压运行，或注册成系统服务）。

2. 「设备管理 → 生成注册码」。

3. 教室机装插件（市场搜「IslandHub 接收端」）→ 填码 → 立即同步。

教学场景里常用的几项

场景怎么做 临时换课 / 调休「快捷换课」按日期改某几节，或整班按另一张课表上课 期中考试「考试模式」一键切考试档案，考完自动还原 走班制按星期与时段自动切档案 通知与提醒定时或设备上线触发；也可发到企业微信 / 钉钉 / 飞书群 教室里出问题远程看截图、前台进程、日志，不必跑到教室 到点开关机定时关机 / 网络唤醒（需在 BIOS 与网卡开启 WoL）

要求

  • 教室端：Windows 上的 ClassIsland 2.1.1.1 及以上。
  • A 端：.NET 10 运行时，或用「自带运行时」安装包（约 48 MB，解压即跑）。
  • 面向校园内网；公网访问请自行加反向代理与 HTTPS。
