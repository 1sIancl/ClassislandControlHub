# 常见问题（FAQ）

> 这份是**独立成篇的 FAQ**（路线图 #100）。`USAGE.md` 第六节只留一句指引，答案都收在这里，
> 免得同一件事在两处各写一遍、然后各改一半。
>
> 按「现象 → 原因 → 处理」组织。多数条目末尾给了「怎么确认修好了」。

## 账号与登录

| 问题 | 处理 |
|---|---|
| 忘记管理员密码 | 服务端 `data/controlhub.db` 的 `users` 表可重置；或者重新初始化数据目录（会丢全部数据，**先备份**）。 |
| 登录后提示「账号被临时锁定」 | 连续失败次数过多触发了锁定策略，稍等几分钟再试；或让超级管理员在「系统 → 账号与权限」里处理。 |
| 界面突然变成英文 | 右上角语言下拉被切到了 English（多语言自 1.4.5 起可用）。切回「简体中文」即可，选择记在本机浏览器里。 |
| 某些页面看不到 / 按钮点不了 | 账号权限是按「权限键」授的。让超管在「账号与权限」里给你的账号勾上对应权限；页面侧栏没出现，多半是连读权限都没有。 |

## 设备与教室端

| 问题 | 处理 |
|---|---|
| 设备列表看不到新设备 | ① 防火墙放行 `29800`（管理端 / 配置）与 `29810`（发现）；② 注册码是否过期或用尽；③ 教室端填的服务器地址是否可 ping 通、http/https 有没有写错。 |
| 提示「注册码不存在」 | 先确认用的是**设备注册码**（「设备管理 → 注册码」），不是**账号邀请码**（「账号与权限 → 注册码」）。两者名字像，用途完全不同：前者给教室端接入选台，后者是自助注册管理员账号用的。 |
| 设备在线但一直「待同步」 | 到该设备的「日志 / 诊断」看客户端报什么；常见是客户端关闭了自动同步，或时间偏差太大。 |
| 升级插件后「像没升级」 | 改名后入口程序集是 `IslandHub.Plugin.dll`，**直接覆盖解压会把旧的 `ControlHub.Plugin.dll` 留在插件目录里**，宿主可能加载到旧的那份。做法：先清空那个插件文件夹，再解压新包。插件 id 没变，**不需要卸载重装**。 |
| 教室端报「协议不支持」 | 插件与 A 端版本差得太远。两边升到同一版本即可（`USAGE.md` 的版本兼容表列了哪些组合可以直接装）。 |

## 配置与下发

| 问题 | 处理 |
|---|---|
| 改了配置，教室端没变化 | ① 看设备是不是「已同步」；② 「配置下发」页手动推一次；③ 改的是课表 / 时间表的话，确认保存的是**当前这个档案**。 |
| 改了 `appsettings.json` 没生效 | 绝大多数项**改完即生效**（1.5 起支持配置热重载）：看 `/server/info` 的 `configReloadCount` 有没有涨、日志里有没有「配置已热重载」。若日志提示「**需要重启**才会生效」，那是监听地址 / 端口 / 证书 / 数据目录 / 密钥路径 / NTP 与发现端口这类**机制上没法热改**的项。另外：**环境变量（`ControlHub__Xxx`）改不动运行中的进程**，要热改就改文件。 |
| 保存时提示 JSON 有问题 | 配置写成非法 JSON 时改动**不生效也不崩**（服务照常跑），日志里会留记录——先把 JSON 修好。 |
| 作息时间对不上 | 用档案编辑器「时间表」页的**时间轴**拖动调整（吸附 5 分钟、自动避让相邻时间点）；保存后服务器会按「上课」时间点重排课表节次，所以**删掉中间某一节，它后面的科目会整体前移一位**。 |

## 备份、恢复与迁移

| 问题 | 处理 |
|---|---|
| 升级后注册码全失效、Webhook 报「密钥不可用」 | 数据目录里的加密密钥 `secrets.key` 丢了或被换了（换机器、或恢复备份时只搬了 `controlhub.db`）。找回原密钥放回去即恢复；确实找不回就重新生成注册码、重填 Webhook 密钥。详见 [`security.md`](security.md)。 |
| 换服务器 / 整机搬迁 | **数据目录整个搬**：`controlhub.db` 与 `secrets.key` 必须一起搬。备份包对外发送时**不要带密钥文件**。 |
| 只想把「配好的东西」搬到另一台已有服务器 | 「系统维护 → **数据迁移**」：导出 JSON 包 → 目标服务器上「选择迁移包…」→ **先看逐表预览** → 确认导入。包里**不含设备令牌 / 账号密码 / Webhook 密钥**，因此设备导入后是「预注册占位」（教室端重新注册时按机器名认领它的分组 / 档案），新导入的账号要重置一次密码。导入会**自动先备份**，拿错包能回退。 |
| 恢复备份为什么要别人确认 | 它会**整库覆盖**。非超级管理员点下去只是提交「操作审批」，超管在「系统 → 操作审批」确认后才执行；驳回则不执行且留痕。 |
| 更新完发现新版本有问题 | 「系统维护 → 自动更新」卡片里有**程序文件快照**（更新前自动拍、只留最近 3 份），可以**一键回滚**到上一个版本；回滚前还会自动再拍一份，所以回滚本身也能撤销。详见 [`upgrade.md`](upgrade.md)。 |

## 通知与提醒

| 问题 | 处理 |
|---|---|
| 提醒到点没动静 | ① 提醒是否启用、时间是否按「时区 + 时间偏移」理解；② 「到时做什么」选的是提示、关机还是唤醒——后两者有前提（网络唤醒需要目标机器与网络支持）。 |
| Webhook 收不到 | 在 Webhook 详情里看「投递记录」：失败原因（超时 / 4xx / 5xx）会逐条写出来；密钥类字段不会回显，只能重新填。 |

## 其它

| 问题 | 处理 |
|---|---|
| 想用脚本对接 IslandHub | 服务端提供机器可读的 **OpenAPI 3.1** 规范：`GET /api/v1/admin/openapi/v1.json`（要登录 + `settings.read`），每条接口都标了鉴权方式与所需权限键，可直接导入 Apifox / Postman / `openapi-generator`。详见 [`api.md`](api.md)。 |
| 想把接口清单关掉 | `ControlHub:EnableOpenApi=false`（改完即生效）。 |
| 界面在大屏上字太小 / 想只留数据 | 「系统 → 大屏看板」：30 秒自动刷新 + 大时钟，点「看板模式」会收起侧栏与顶栏，整屏留给数据。 |
