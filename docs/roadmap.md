# 路线图与建议清单

本文件是项目 backlog 的单一事实来源：按优先级分组，每条都标注当前状态，避免「提过但没人记得做没做」。

状态标记：

| 标记 | 含义 |
|---|---|
| ✅ | 已完成（含已完成但实现方式不同的情况，会在条目里说明） |
| 🔨 | 部分完成，已实现主线、还缺若干细节 |
| ⬜ | 待办 |

> 落地原则：**先冻结协议，再写实现**（见 [插件扩展协议](plugin-protocol.md)）。协议反复改的代价远大于功能晚一点上。

## 建议的推进顺序

1. **P0 已清空**：`#4` 指令队列可视化、`#5` 下发 diff 预览均已完成（见上表）。
2. **设置页加载会被更新检查拖住（实测发现，待修）**：`settings.js` 的 `render()` 用 `Promise.all`
   等**全部**接口返回，其中 `/admin/update/state` 需要访问 GitHub；网络受限或 GitHub 慢时，
