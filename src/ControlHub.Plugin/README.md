# 集控客户端（ControlHub）

ClassIsland 集控系统的 B 端客户端插件。接入集控服务器（A 端）后，可自动接收并应用
由管理员统一下发的**时间表、课表、科目**以及**自定义设置**，实现全校教室大屏的集中配置管理。

## 功能

- **自动发现服务器**：同一局域网内一键发现集控服务器，无需手动抄写 IP。
- **设备注册**：通过管理员生成的注册码接入，支持安全令牌与断线重连。
- **自动同步**：长轮询即时接收服务器推送，配置变更数秒内到达教室大屏。
- **分区控制**：可分别开关「时间表 / 课表 / 科目 / 自定义设置」的接收与应用。
- **离线容错**：记录已应用版本，重复推送不会重复覆盖，令牌失效自动重新注册。
- **运行日志**：设置页内实时查看连接与同步日志，便于排查问题。

## 使用

1. 在服务器 Web 端「设备管理 → 注册码」中生成注册码。
2. 安装本插件后打开【应用设置 → 集控客户端】。
3. 点击「自动发现服务器」，或手动填写服务器地址（如 `http://192.168.1.5:29800`）。
4. 填入注册码，点击「保存设置」，再点击「立即同步」。

## 说明

- 集控下发的配置会**替换**本机对应分区（时间表/课表/科目），用于统一管理场景。
- 服务器若使用自签名 HTTPS，请勾选「允许不受信任的 HTTPS 证书」。

> 本项目是 ClassIsland 集控系统的一部分，服务端见仓库根目录。
